# Architecture Decision Records (ADR)

This directory contains records of the major architectural decisions made for the Ente Kottakkal Flutter Shell project.

## List of ADRs

1. [WebView-based Architecture](0001-webview-based-architecture.md) - Why we use a WebView shell for the Next.js app.
2. [JavaScript Bridge for Native Features](0002-javascript-bridge-for-native-features.md) - How the web app communicates with native mobile features.
3. [Back Button and Exit Strategy](0003-back-button-and-exit-strategy.md) - Custom handling for the Android physical back button.
4. [External URL Handling](0004-external-url-handling.md) - Intercepting and redirecting specialized links to native apps.
